# 🎬 Video → GIF Converter

GIf converter fully vibe coded with Claude. Perfect if you don't want to deal with pesky websites that do the same thing and ask for payment.

Convert `.mp4` and `.mov` videos to animated GIFs on macOS. Includes a command-line script, a drag-and-drop launcher, and an interactive menu — no coding required to use. Cin

## ⚙️ Requirements

- Python 3.8+
- [moviepy](https://github.com/Zulko/moviepy)

Install the dependency:
```bash
pip install moviepy
```

---

## 🚀 Setup (One-Time)

Make the `.command` files executable by running this in Terminal:

```bash
chmod +x "/path/to/gif converter/drag_and_drop_convert.command"
chmod +x "/path/to/gif converter/convert_menu.command"
```

---

## 🖱️ Usage

### Option 1 — Drag & Drop
Drag any `.mp4` or `.mov` file onto `drag_and_drop_convert.command` in Finder.
It will prompt you for optional resize/fps settings, then save the GIF next to your video.

### Option 2 — Interactive Menu
Double-click `convert_menu.command`. Choose from:
- **Quick convert** — default settings (12 fps, original size, full length)
- **Custom convert** — set fps, resize width, and trim start/end times
- **Help** — tips and examples

### Option 3 — Command Line
```bash
cd "/path/to/gif converter"

# Basic
python3 video_to_gif.py input.mp4

# Custom output path
python3 video_to_gif.py input.mov -o output.gif

# Trim, resize, set fps
python3 video_to_gif.py input.mp4 --start 5 --end 15 --width 480 --fps 15
```

---

## 🎛️ Options

| Flag | Default | Description |
|---|---|---|
| `-o` | same as input | Output `.gif` path |
| `--fps` | `12` | Frames per second |
| `--width` | original | Resize width in px (keeps aspect ratio) |
| `--start` | `0` | Trim start time in seconds |
| `--end` | full video | Trim end time in seconds |
| `--no-optimize` | off | Skip file size optimization |

---

## 💡 Tips for Smaller GIF Files

GIFs can get large fast. To keep file sizes manageable:

- **Lower fps** — `--fps 8` or `--fps 10` is usually smooth enough
- **Resize down** — `--width 480` is a good default for web use
- **Trim your clip** — only convert the segment you actually need with `--start` / `--end`

---

## 📝 Notes

- Output GIF is saved in the same directory as the input video by default
- Optimization is enabled by default via moviepy's `OptimizePlus` setting
- Audio is not included in GIF output (GIFs don't support audio)
